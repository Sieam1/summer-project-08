# ☀️ SunCart – Summer Essentials Store

A modern, fast, and responsive e-commerce web application built for selling summer essentials like clothing, accessories, and lifestyle products.

Built with **Next.js 16**, **Tailwind CSS**, **DaisyUI**, and authentication powered by **Better Auth**.

---

## 🚀 Features

- 🛍️ Product listing with dynamic product pages  
- 🔎 Product details page (`/products/[id]`)  
- 🔐 User authentication (Login / Register)  
- 👤 User profile dashboard  
- ⚡ Fast performance with Next.js App Router  
- 🎨 Modern UI using Tailwind CSS + DaisyUI  
- 📱 Fully responsive design (mobile-first)  
- 🖼️ Optimized images using Next.js Image component  
- 🔗 API routes for backend functionality  

---

## 🧰 Tech Stack

- Next.js 16  
- React  
- Tailwind CSS  
- DaisyUI  
- MongoDB  
- Better Auth
